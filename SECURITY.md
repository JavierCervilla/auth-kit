# Security policy

auth-kit handles sign-in, so security reports are welcome and taken seriously.

## Reporting a vulnerability

Please report it privately through GitHub: open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for it.

Include what you found, how to reproduce it and the version or commit you tested. You will get an answer within a few
days.

## Supported versions

Before `v1.0.0`, only the latest tag gets security fixes.
